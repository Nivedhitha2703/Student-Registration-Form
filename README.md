# Student Registration Form

A simple and user-friendly Student Registration Form developed using HTML. This project demonstrates the use of various HTML form elements to collect student information efficiently.

## Features

* Student Roll Number Input
* Student Name (First Name & Last Name)
* Father's Name Field
* Date of Birth Selection
* Mobile Number Input
* Email Address Input
* Password Field
* Gender Selection
* Department Selection
* Course Selection Dropdown
* Student Photo Upload
* City Input
* Address Text Area
* Registration Submission Button

## Technologies Used

* HTML5

## Purpose

This project was created to practice HTML forms and understand different input types, including text fields, radio buttons, checkboxes, dropdown menus, file uploads, and text areas.

## Learning Outcomes

* Creating HTML forms
* Using various input types
* Organizing form data collection
* Building user-friendly registration interfaces

## Future Enhancements

* Add CSS styling for a modern design
* Implement JavaScript form validation
* Connect the form to a database
* Improve responsiveness for mobile devices
